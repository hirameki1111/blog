# 키워드(+관련 자료) → 창의적 블로그 글 생성기

키워드 1개와 **관련 자료 파일(txt / pdf)**을 입력하면, 그 내용을 반영해
GPT API로 창의적인 한국어 블로그 글을 작성해 주는 프로그램입니다.
자료 없이 키워드만으로도 동작합니다.

**두 가지 사용 방식이 있습니다.**
- **GUI 버전** (`blog_writer_gui.py`) — 파일 첨부 버튼으로 txt/pdf를 붙이고 버튼으로 생성
- **CLI 버전** (`blog_writer.py`) — 터미널에서 키워드/파일 경로를 인자로 전달

## 가성비 모델 선택

| 모델 | 품질 | 가격(대략) | 장문 생성 가성비 |
|------|------|-----------|----------------|
| gpt-4o | 최상 | 비쌈 | 낮음 |
| **gpt-4o-mini** | **상 (GPT-4 근접)** | **매우 저렴 (4o의 ~1/30)** | **★ 최고** |
| gpt-4.1-mini | 상 | 저렴 | 좋음 |

- 창의적 블로그 글은 **장문(출력 토큰 多)** 작업이라 출력 비용이 핵심입니다.
- `gpt-4o-mini`는 충분히 좋은 글쓰기 품질에 가격이 매우 저렴해 **가성비가 가장 우수**합니다.
- 기본값은 `gpt-4o-mini`이며, 환경변수 `OPENAI_MODEL`로 교체할 수 있습니다.

## 설치

```powershell
pip install -r requirements.txt
```

## API 키 설정 (PowerShell)

```powershell
$env:OPENAI_API_KEY = "sk-..."
```

## 실행 — GUI 버전 (권장)

```powershell
python blog_writer_gui.py
```

1. **키워드** 입력란에 주제 키워드를 적습니다.
2. **파일 첨부** 버튼으로 `txt` / `pdf` 자료를 원하는 만큼 추가합니다. (선택 삭제·전체 삭제 가능)
3. **나의 관점** 칸에 글에 담고 싶은 시각·주장을 200자 내외로 적습니다. (선택, 실시간 글자 수 표시)
4. **글 스타일**을 `친근하게` / `진지하게` 중에서 선택합니다. (기본: 친근하게)
5. **블로그 글 생성** 버튼을 누르면 GPT가 글을 작성합니다. (생성 중 창이 멈추지 않도록 백그라운드 처리)
6. **저장(.md)** 버튼으로 결과를 마크다운 파일로 저장합니다.
7. **초기화** 버튼으로 모든 입력과 생성 결과를 처음 상태로 되돌립니다.

## 실행 — CLI 버전

```powershell
# 키워드 + 관련 자료 파일 1개 (txt 또는 pdf)
python blog_writer.py 가을여행 sample_material.txt
python blog_writer.py 가을여행 report.pdf

# 키워드 + 관련 자료 파일 여러 개 (txt/pdf 혼합 가능)
python blog_writer.py 가을여행 자료1.txt 자료2.pdf

# 키워드만 (자료 없이)
python blog_writer.py 가을여행

# 키워드 + 글쓴이 관점 (200자 내외) + 스타일
python blog_writer.py 가을여행 자료.pdf --viewpoint "나는 가을이 사색의 계절이라고 본다..." --style 진지하게

# 인자 없이 실행하면 키워드 / 자료 파일 / 관점 / 스타일을 차례로 물어봅니다.
python blog_writer.py
```

- 첫 번째 인자는 **키워드**, 그 뒤의 인자들은 **관련 자료 파일 경로**입니다.
- `--viewpoint "..."` 로 **글쓴이의 관점**(200자 내외)을 전달하면, 그 시각과 논조가 글 전체에 반영됩니다.
- `--style 친근하게|진지하게` 로 **글의 말투**를 지정합니다. (기본: 친근하게)
- 텍스트 파일은 `utf-8` / `cp949` 인코딩을 자동 감지해 읽습니다.
- **PDF 파일**은 `pypdf`로 텍스트를 추출합니다. (스캔 이미지형 PDF는 텍스트가 없어 추출되지 않을 수 있습니다.)
- 자료가 너무 길면 비용 보호를 위해 앞부분 일부만 사용합니다(기본 12,000자).
- 생성된 글은 화면에 출력되고 `blog_<키워드>.md` 파일로도 저장됩니다.

### 관련 자료 파일이란?

블로그에 녹이고 싶은 사실·정보·수치를 담은 `.txt` 또는 `.pdf` 파일입니다.
예시는 저장소의 [`sample_material.txt`](sample_material.txt)를 참고하세요.
모델은 자료의 내용을 우선 반영하고, 자료에 없는 사실은 지어내지 않도록 지시받습니다.
